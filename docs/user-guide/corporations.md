# 军团管理

军团页面展示你所在军团的整体数据，包括成员列表、财务信息等。访问军团页面需要相应权限。

## 进入军团页面

方式一：**侧边栏 → 军团**，查看你所在军团的信息。

方式二：在角色详情页点击角色的**军团名称**链接，跳转到该军团页面。

## 军团概览

军团概览页显示：

| 字段 | 说明 |
|------|------|
| 军团名称 | 军团全名 |
| 军团代号 | \[TICK\] |
| 所在联盟 | 当前所属联盟（若有） |
| 成员总数 | 军团当前成员数 |
| 创建时间 | 军团成立日期 |
| CEO | 军团 CEO 角色名 |
| 描述 | 军团简介（EVE 内设置） |

## 成员列表

成员列表标签页展示军团所有成员：

- 角色名、头像
- 加入军团时间
- 角色所在联盟（若为联盟军团）
- 支持按角色名搜索

!!! note "权限要求"
    查看成员列表通常需要 `corporation.view_members` 权限或更高权限。ESI 数据需要 `esi-corporations.read_corporation_membership.v1` scope。

## 军团财务

财务标签页（需 `corporation.view_finances` 权限）显示：

- **军团钱包余额**：各分类钱包（Division 1–7）的 ISK 余额
- **流水记录**：收支明细，包含时间、类型、金额、备注

## 军团邮件

邮件标签页（需相应权限）展示发送到全体成员的军团邮件，格式与角色邮件相同。

## 军团资产

资产标签页（需 `corporation.view_assets` 权限）展示军团名下的所有资产，包括：
- 军团仓库物品
- 空间站库存
- 舰船停泊

每条资产记录显示物品图标（来自 EVE 官方图像服务器）、物品名称、所在位置、数量等信息。

## 数据更新频率

军团数据由 Celery Worker 定期从 ESI 拉取：

| 数据类型 | 更新频率 |
|---------|---------|
| 基本信息 | 1 小时 |
| 成员列表 | 1 小时 |
| 财务 | 1 小时 |
| 资产 | 6 小时 |
