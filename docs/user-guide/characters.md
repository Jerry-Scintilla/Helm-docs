# 角色管理

角色页面展示你绑定的 EVE 角色的详细信息，数据通过 ESI API 实时同步。

## 角色列表

进入 **侧边栏 → 角色**，可以看到你绑定的所有角色。每个角色卡片显示：

- 角色头像
- 角色名称
- 所在军团与联盟
- 技能点总数
- 钱包余额

点击角色卡片进入该角色的详情页。

## 角色详情页

### 基本信息

| 字段 | 说明 |
|------|------|
| 角色名 | EVE 角色全名 |
| 种族 | Caldari / Minmatar / Amarr / Gallente |
| 军团 | 当前所在军团名称，点击可进入军团页面 |
| 联盟 | 当前所在联盟名称 |
| 加入军团时间 | 角色加入当前军团的时间戳 |
| 安全等级 | EVE 角色安全状态 |

### 技能

技能标签页显示角色的技能学习情况：

![技能](https://raw.githubusercontent.com/Helm-docs/img/main/screenshot/%E6%8A%80%E8%83%BD%EF%BC%88%E4%B8%AD%E6%96%87%EF%BC%89.jpeg)

- **已学技能列表**：按技能组分类，显示每项技能的当前等级（1–5）
- **技能点数**：总技能点、各技能组技能点分布
- **技能队列**：当前正在学习的技能和完成时间

!!! note
    技能数据需要在 EVE SSO 授权时包含 `esi-skills.read_skills.v1` scope。

### 资产

资产标签页列出角色名下的所有物品：

![资产](https://raw.githubusercontent.com/Helm-docs/img/main/screenshot/%E8%B5%84%E4%BA%A7%EF%BC%88%E4%B8%AD%E6%96%87%EF%BC%89.jpeg)

- 显示物品图标、名称、数量、所在位置（星系/空间站）
- 支持按物品名称、类型、位置筛选
- 显示估值（ISK）

物品图标来自 EVE 官方图像服务器，按位置分组展示，容器类物品（如货柜、飞船货舱）可展开查看内部物品。

### 钱包

钱包标签页包含：

- **ISK 余额**：当前账户余额
- **钱包流水**：交易记录，包含时间、类型、金额、描述

### 邮件

邮件标签页展示角色的 EVE 邮件：

- 收件箱列表，显示发件人、主题、时间
- 点击可展开邮件正文（支持 EVE 邮件 HTML 渲染）

### 通知

系统通知标签页展示 EVE 游戏内的系统通知，如：

![通知](https://raw.githubusercontent.com/Helm-docs/img/main/screenshot/%E9%80%9A%E7%9F%A5%EF%BC%88%E4%B8%AD%E6%96%87%EF%BC%89.jpeg)

- 结构被攻击
- 军团申请
- 合同完成
- 行星采集提醒

## 插件扩展

如果管理员安装了角色扩展插件，角色详情页还可能出现额外的数据卡片或子标签页：

- **Widget（数据卡片）**：注入到角色详情页顶部区域，展示插件提供的简要数据
- **子模块（子标签页）**：以独立标签页形式呈现，提供完整的插件功能界面

例如：PAP 活跃度追踪插件可以在角色页面注入「本月参战记录」卡片。

## 数据更新频率

| 数据类型 | 更新频率（近似） |
|---------|--------------|
| 基本信息 | 1 小时 |
| 技能 | 1 小时 |
| 资产 | 1–6 小时 |
| 钱包 | 30 分钟 |
| 邮件 | 30 分钟 |
| 通知 | 30 分钟 |

实际频率取决于 ESI 缓存头和 Helm 的桶配置。
