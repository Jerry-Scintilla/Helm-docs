# 用户指南

欢迎使用 Helm！本章面向日常使用 Helm 的舰队成员和军团管理者，介绍核心功能的使用方法。

## 快速上手

```
1. EVE SSO 登录           → 用 EVE 账号一键授权
2. 查看控制台             → 了解军团和角色概况
3. 查看角色详情           → 技能、资产、钱包
4. 查看军团信息           → 成员、财务
5. 安装插件（管理员）      → 扩展更多功能
```

## 权限说明

Helm 使用 RBAC（基于角色的访问控制）。不同用户能看到的内容取决于管理员为其分配的权限：

- **全局权限**：如 `admin.manage_plugins`，控制全局功能
- **角色级权限**：如查看特定角色的资产
- **军团级权限**：如查看军团财务
- **联盟级权限**：如查看联盟成员列表

如果你看不到某个功能，请联系 Helm 管理员分配相应权限。
