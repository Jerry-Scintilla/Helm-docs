# Alliance Management

The Alliance page shows overall alliance information and its member corporation list.

## Navigating to the Alliance Page

**Option 1:** **Sidebar → Alliance**

**Option 2:** Click the alliance name link on a character detail or corporation page

## Alliance Overview

| Field | Description |
|-------|-------------|
| Alliance Name | Full alliance name |
| Ticker | \<TICK\> |
| Member Corp Count | Total number of current member corporations |
| Executor Corp | The corporation that leads the alliance |
| Founded | Alliance creation date |

## Member Corporation List

The Member Corporations tab lists all corporations in the alliance:

- Corporation name and ticker
- Member count
- Date joined the alliance
- Click a corporation name to navigate to that corp's page (requires permission)

!!! note
    Viewing the alliance member list requires `alliance.view_members` permission.

## Alliance Finances

Alliance-level financial data (if available) showing the alliance's overall income and expenses.

## Data Refresh Frequency

| Data Type | Frequency |
|-----------|-----------|
| Basic info | 1 hour |
| Member corporations | 1 hour |
