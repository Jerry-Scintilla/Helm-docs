# 联盟管理

联盟页面展示联盟的整体信息和成员军团列表。

## 进入联盟页面

方式一：**侧边栏 → 联盟**

方式二：在角色详情或军团页面点击联盟名称链接

## 联盟概览

| 字段 | 说明 |
|------|------|
| 联盟名称 | 联盟全名 |
| 联盟代号 | \<TICK\> |
| 成员军团数 | 当前成员军团总数 |
| 创始军团 | 创立联盟的军团 |
| 创建时间 | 联盟成立日期 |

## 成员军团列表

成员军团标签页列出联盟下所有军团：

- 军团名称、代号
- 成员数
- 加入联盟时间
- 点击军团名称可跳转至该军团页面（需权限）

!!! note
    查看联盟成员列表需要 `alliance.view_members` 权限。

## 联盟财务

联盟层级财务数据（若可用），展示联盟整体收支情况。

## 数据更新频率

| 数据类型 | 更新频率 |
|---------|---------|
| 基本信息 | 1 小时 |
| 成员军团 | 1 小时 |
