# 控制台

控制台（Dashboard）是登录 Helm 后的主界面，提供军团和角色数据的总览。

![控制台总览](https://raw.githubusercontent.com/Helm-docs/img/main/screenshot/%E6%80%BB%E8%A7%88%EF%BC%88%E4%B8%AD%E6%96%87%EF%BC%89.jpeg)

## 界面区域

### 顶部统计卡片

登录后，控制台顶部显示关键统计数据：

| 卡片 | 说明 |
|------|------|
| 绑定角色数 | 当前账户绑定的 EVE 角色总数 |
| 军团成员数 | 你所在军团的当前在线/总成员数 |
| 资产估值 | 所有绑定角色的资产总 ISK 估值（需权限） |
| 最近活动 | 最近的 ESI 数据同步时间 |

### 侧边栏导航

侧边栏包含两部分：

**核心功能**（始终显示）：
- **控制台** — 返回主页
- **角色** — 查看绑定角色列表
- **军团** — 查看军团信息
- **联盟** — 查看联盟信息

**插件菜单**（由已启用的插件注入）：
- 具体条目取决于管理员安装了哪些插件
- 例如：「市场扫描」、「PAP 追踪」、「舰队调度」等

### 主内容区

控制台主内容区根据你的权限显示不同的信息面板，可能包括：
- 近期击杀记录（需安装击杀统计插件）
- 军团事件提醒
- ESI 数据同步状态

## 快捷入口

| 操作 | 位置 |
|------|------|
| 查看某个角色详情 | 侧边栏 → 角色 → 点击角色名 |
| 切换当前角色 | 右上角头像下拉菜单 |
| 进入管理后台 | 右上角头像 → 管理后台（仅管理员可见） |
| 查看 API Token | 右上角头像 → 账户设置 |
| 注销 | 右上角头像 → 注销 |

## ESI 数据刷新状态

控制台底部或角色页面可能显示 **数据同步时间**，表示 ESI 数据的最后更新时间。Helm 通过后台 Celery 任务定期刷新，一般延迟在 15–60 分钟之间，具体取决于桶的配置和 ESI 速率限制。
