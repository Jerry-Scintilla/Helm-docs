# 管理员指南

本章面向 Helm 实例的管理员，介绍用户权限管理、插件管理和后台任务监控。

## 进入管理后台

登录后，点击右上角头像 → **管理后台**，进入 `/admin` 页面。

!!! note "权限要求"
    管理后台仅对拥有 `global.superuser` 权限的用户开放。首次部署时通过系统自动生成的一次性授权链接获取超级管理员权限，详见 [超级管理员初始化](superuser-setup.md)。

## 管理后台功能

| 功能区 | 路径 | 说明 |
|--------|------|------|
| 系统状态 | `/admin/system` | 查看服务运行状态与统计数据 |
| 用户权限 | `/admin/users` | 为用户分配角色和权限 |
| SDE 数据 | `/admin/sde` | 导入/更新游戏静态数据 |
| 插件管理 | `/admin/plugins` | 安装、启用、禁用、卸载插件 |
| **插件市场** | — | 查看官方插件列表、版本与功能说明 |
| 任务历史 | `/admin/tasks` | 查看后台任务执行记录 |
| **市场物价** | `/admin/market` | 设置默认查询星域，测试物价服务 |
