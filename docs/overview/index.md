# 什么是 Helm

Helm 是一个面向 EVE Online 军团和联盟的**开源舰队管理与行政平台**。它通过 CCP 官方的 EVE Swagger Interface (ESI) API 实时同步游戏数据，为管理员和成员提供统一的 Web 界面，并通过插件系统支持无限功能扩展。

## 设计目标

| 目标 | 说明 |
|------|------|
| **开放扩展** | 插件系统允许任何开发者为特定军团场景添加自定义功能，无需修改主体代码 |
| **最小运维** | 热加载插件、异步 ESI 刷新、自动数据库迁移，尽量减少管理员手动干预 |
| **权限精细** | 四维度 RBAC 确保不同角色只能看到、操作自己权限范围内的数据 |
| **数据实时** | ESI 缓存层支持逻辑过期与后台刷新，尽量提供最新游戏数据 |

## 核心能力

### 身份与认证
- EVE Online SSO（OAuth 2.0）单点登录，支持多角色绑定
- JWT 会话令牌 + 长效 API Token（程序化访问）
- 细粒度的 RBAC 权限控制

### 数据同步
- 角色：技能、资产、钱包、邮件、通知、联系人
- 军团：成员列表、资产、财务、军团邮件
- 联盟：成员军团、联盟概览
- ESI 桶式速率限制，防止 API 封禁

### 插件系统
- 基于 Python wheel 包，支持从 PyPI 或本地 `.whl` 安装
- 插件可注册 FastAPI 路由（热挂载，无需重启）
- 插件可注册 Celery 后台任务（Worker 软重启生效）
- 插件可声明权限、ESI 作用域、侧边栏菜单项
- 插件可提供 iframe 前端页面（任意技术栈）
- 插件间通信通过 `ExtensionRegistry` 实现

### 管理后台
- 插件安装 / 启用 / 禁用 / 卸载
- 任务运行历史查看
- 用户权限管理

## 适用场景

=== "军团管理员"
    - 统一查看全军团成员角色的技能、资产、钱包状态
    - 安装自定义插件（如 PAP 活跃度追踪、舰队调度、击杀统计）
    - 管理成员权限，区分高管、普通成员、访客

=== "舰队成员"
    - 通过 EVE SSO 一键登录，无需注册额外账户
    - 查看自己的角色信息、资产、钱包明细
    - 接收军团通知

=== "插件开发者"
    - 使用插件系统为军团开发定制功能
    - 利用 ExtensionRegistry 与其他插件通信
    - 通过 HelmSDK 构建 iframe 前端页面

=== "API 集成者"
    - 使用 API Token 通过 REST API 查询 Helm 数据
    - 集成到外部工具（Discord Bot、外部仪表盘等）

## 与同类工具的对比

Helm 与 [SeAT](https://seat.docs.eve-tools.xyz/) 等工具定位相近，核心差异在于：

| 特性 | Helm | SeAT |
|------|------|------|
| 技术栈 | FastAPI + Vue 3（Python / TS） | Laravel（PHP） |
| 插件系统 | 原生热加载，无需重启 | 需要重新加载 |
| 前端架构 | Vue 3 SPA + 插件 iframe | Blade 模板 |
| 异步支持 | 全程 asyncio | 同步为主 |
| 开源协议 | GPL-2.0 | MIT / GPL |
